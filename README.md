# Alien Shooter 🚀

A simple 2D shooting game built using Python and Pygame.

## Features
- Spaceship movement
- Alien enemy
- Bullet shooting
- Score system
- Levels
- Lives system
- Game over screen

## Technologies Used
- Python
- Pygame

## Controls
- Left Arrow → Move Left
- Right Arrow → Move Right
- Spacebar → Shoot
